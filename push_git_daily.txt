# Git & GitHub 初始化项目笔记

## 第一步：本地项目初始化
# 1. 打开 Cursor 终端（Ctrl + `），初始化本地 Git 仓库
git init

# 2. 创建或修改文件（比如新建 README.md）后，将所有变动添加到暂存区（注意 add 后面有一个空格和点）
git add .

# 3. 将暂存区的文件提交到本地仓库，并写下提交说明
git commit -m "首次提交：初始化项目"

# 4. 确保本地主分支的名称被规范命名为 main
git branch -M main


## 第二步：关联远程 GitHub 仓库并首次推送
# 5. 将本地仓库与你创建好的 GitHub 远程仓库进行绑定
git remote add origin https://github.com/oficeroes/BainPoison.git

# 6. 将本地代码首次推送到云端（此时可能会弹出浏览器要求你授权登录 GitHub，按提示允许即可）
git push -u origin main


## 第三步：日常开发“三板斧”（以后每天写新代码时重复使用）
# 7. 每当你写完一部分新代码，想要更新到 GitHub 时，依次运行以下三条：
git add .
git commit -m "完成了某某新功能的编写"
git push
